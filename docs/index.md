# Syschecks Provider

The Syschecks (SysTeam Healthchecks) provider lets you manage your monitoring,
on-call and incident-response configuration as code: checks (uptime, HTTP, DNS,
database, API scenarios and more), projects, status pages, notification channels,
escalation policies, on-call schedules, SLOs, teams, services, integration keys,
contact methods, lifecycle watches and multi-stage playbooks.

Works with both **Terraform** and **OpenTofu**.

## Example Usage

```terraform
terraform {
  required_providers {
    systeam = {
      source  = "systeampl/systeam"
      version = "~> 0.1"
    }
  }
}

provider "systeam" {
  # Base URL of the Syschecks API (no /api suffix). Or set SYSTEAM_API_URL.
  api_url = "https://syschecks.com"

  # A Personal Access Token (pat_...). Or set SYSTEAM_API_TOKEN.
  api_token = var.systeam_token
}
```
